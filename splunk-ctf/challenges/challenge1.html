📚CONCEPTS TO LEARN

What is Splunk?

Splunk is a powerful SIEM platform for searching, monitoring, and analyzing machine-generated data. Security teams use it to detect threats, investigate incidents, and monitor events in real-time.

Search Processing Language (SPL)

SPL is Splunk's query language. Every search starts with a search term and can be piped through multiple commands.

  • index= - Specifies which data index to search
  • sourcetype= - Filters by the type of data source
  • source= - Filters by the specific source file
  • host= - Filters by the hostname

Basic SPL Syntax

SPL
index=main sourcetype=access_log status=404
| stats count by clientip
| sort -count
| head 10

This search: finds 404 errors → counts by IP → sorts descending → shows top 10

Essential SPL Commands

statsCalculates aggregate statisticsstats count by user

🎯THE CHALLENGE

SITUATION: Our SOC received an alert about suspicious login activity. You have web server access logs from the past week. Find the IP address that made the most failed login attempts (HTTP 401 errors).

FLAG FORMAT
FLAG{IP_ADDRESS}
📥 Download Challenge Data
💡 HINT

HTTP 401 = "Unauthorized" (failed auth). Use stats count by clientip to aggregate.

🔓SOLUTION

Search for Failed Authentication Events

Search for all HTTP 401 status codes:

SPL
index=web sourcetype=access_combined status=401

Count Events by IP Address

SPL
index=web sourcetype=access_combined status=401
| stats count by clientip

Sort to Find Top Offender

SPL
index=web sourcetype=access_combined status=401
| stats count by clientip
| sort -count
| head 1
