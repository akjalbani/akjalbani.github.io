🌐 Web Shell Hunter

MEDIUM 200 POINTS ~35 MIN T1505.003

Find the hidden web shell planted by attackers in Apache access logs.

📚CONCEPTS TO LEARN

What is a Web Shell?

A web shell is a malicious script uploaded to a web server that provides attackers with remote access and command execution. Common types include PHP, ASP, and JSP shells.

  • Indicators: Unusual file names, POST requests to uncommon files
  • Behavior: Command execution via URL parameters (cmd=, c=, exec=)
  • MITRE ATT&CK: T1505.003 - Server Software Component: Web Shell

Web Shell Detection Patterns

PatternDescriptionExample
Suspicious file extensionsPHP/ASP in unusual directories/images/shell.php
Command parametersURL params suggesting exec?cmd=whoami
POST to static filesPOST requests to image dirsPOST /uploads/img.php
Base64 in URLsEncoded commands?c=d2hvYW1p
Unusual User-AgentsNon-browser agentspython-requests, curl

Using regex in SPL

The rex command extracts fields using regular expressions:

SPL
index=web sourcetype=access_combined
| rex field=uri "(?[^/]+\.php)"
| rex field=uri "\?(cmd|c|exec|command)=(?[^&\s]+)"
| where isnotnull(command)

Hunting Techniques

  • Baseline normal: Know what's typical for your environment
  • Look for outliers: Rare URIs, unusual request patterns
  • Correlate: Same IP uploading then accessing files
  • Time analysis: Activity during off-hours

🎯THE CHALLENGE

SITUATION: Your web application firewall flagged suspicious activity but didn't block it. An attacker may have uploaded a web shell. Analyze the Apache logs to find:


1. The name of the web shell file
2. The command the attacker executed through it

FLAG FORMAT
FLAG{FILENAME_COMMAND}
📥 Download Challenge Data
💡 HINT

Look for PHP files being accessed with suspicious parameters. Check for requests to unusual directories like /uploads/ or /images/.

🔓SOLUTION

Find PHP Files in Unusual Locations

SPL
index=web sourcetype=access_combined uri="*.php*"
| rex field=uri "(?/[^?]+)"
| stats count by path
| search path!="/index.php" path!="/login.php" path!="/admin/*"

This reveals /uploads/helpdesk.php - unusual PHP in uploads directory!

Examine Requests to Suspicious File

SPL
index=web sourcetype=access_combined uri="*helpdesk.php*"
| table _time, clientip, method, uri, status, useragent

Extract Command Parameters

SPL
index=web sourcetype=access_combined uri="*helpdesk.php*"
| rex field=uri "\?cmd=(?[^&\s]+)"
| where isnotnull(command)
| table _time, clientip, command

This shows the attacker executed "cat+/etc/passwd" (URL encoded)!

Full Investigation Query

SPL
index=web sourcetype=access_combined 
| rex field=uri "(?[^/]+\.php)"
| rex field=uri "\?(cmd|c|exec)=(?[^&\s]+)"
| where isnotnull(command)
| stats count, values(command) as commands by file, clientip
| sort -count
🚩 THE FLAG
FLAG{helpdesk.php_cat+/etc/passwd}
📝 LESSONS LEARNED

Web shells often hide in plain sight with innocent-looking names. Always investigate PHP files in upload directories and watch for command execution parameters.
