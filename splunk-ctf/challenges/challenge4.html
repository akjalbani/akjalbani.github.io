🖥️ PowerShell Empire

MEDIUM 250 POINTS ~40 MIN T1059.001

Detect malicious PowerShell execution and encoded command attacks.

📚CONCEPTS TO LEARN

PowerShell as an Attack Vector

PowerShell is a powerful scripting language built into Windows. Attackers love it because it's:

  • Native: Pre-installed on all modern Windows systems
  • Powerful: Can access .NET, WMI, COM objects, and more
  • Flexible: Can execute code in memory without touching disk
  • Trusted: Often whitelisted by security tools

Malicious PowerShell Indicators

Windows Event IDs for PowerShell

  • 4104: Script Block Logging - Records PowerShell scripts
  • 4103: Module Logging - Records module usage
  • 400/403: Engine start/stop (legacy)
  • Sysmon 1: Process creation with command line
SPL
index=windows (EventCode=4104 OR source="WinEventLog:Microsoft-Windows-PowerShell/Operational")
| search ScriptBlockText="*EncodedCommand*" OR ScriptBlockText="*-enc*"

Decoding Base64 in Splunk

Attackers often Base64 encode commands. You can decode them in SPL:

SPL
| eval decoded=base64decode(encoded_command)
| eval decoded_utf16=urldecode(replace(decoded,"(..)","\\x\1"))

🎯THE CHALLENGE

SITUATION: Your EDR flagged suspicious PowerShell activity on a workstation. The analyst believes an attacker is using encoded commands to download and execute malware. Analyze the PowerShell logs to find:


1. The hostname of the compromised machine
2. The URL the attacker tried to download malware from

FLAG FORMAT
FLAG{HOSTNAME_DOMAIN}
📥 Download Challenge Data
💡 HINT

Look for -EncodedCommand or -enc flags. The Base64 may need decoding. Search for patterns like "DownloadString" or "WebClient".

🔓SOLUTION

Find Encoded PowerShell Commands

SPL
index=windows sourcetype=WinEventLog:PowerShell
| search "*-enc*" OR "*EncodedCommand*" OR "*-e *"
| table _time, host, CommandLine

This finds PowerShell events with encoding indicators. Host WKSTN-PC47 appears!

Look for Download Indicators

SPL
index=windows sourcetype=WinEventLog:PowerShell
| search "*DownloadString*" OR "*WebClient*" OR "*Invoke-WebRequest*" OR "*iwr*"
| table _time, host, Message

Extract and Analyze Suspicious Commands

SPL
index=windows sourcetype=WinEventLog:PowerShell host="WKSTN-PC47"
| rex field=Message "http[s]?://(?[^\s'\"]+)"
| where isnotnull(malicious_url)
| stats count by malicious_url

Extracted URL: evil-payload.attacker.net

Alternative: Decode Base64

SPL
index=windows sourcetype=WinEventLog:PowerShell
| rex field=CommandLine "-[eE](?:nc|ncodedcommand)?\s+(?[A-Za-z0-9+/=]+)"
| where len(b64cmd) > 20
| eval decoded=base64decode(b64cmd)
| table host, b64cmd, decoded
🚩 THE FLAG
FLAG{WKSTN-PC47_evil-payload.attacker.net}
⚠️ REAL WORLD NOTE

In production, create alerts for these patterns. PowerShell 5.0+ has Script Block Logging (Event 4104) which captures the decoded command automatically!
