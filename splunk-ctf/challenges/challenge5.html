📡 Data Exfiltration

MEDIUM 300 POINTS ~45 MIN T1048

Identify unusual data transfers and DNS tunneling attempts.

📚CONCEPTS TO LEARN

Data Exfiltration Techniques

Attackers use various methods to steal data from compromised networks:

  • DNS Tunneling: Encoding data in DNS queries to bypass firewalls
  • HTTP/HTTPS: Using web traffic to blend in with normal traffic
  • Cloud Services: Uploading to legitimate cloud storage
  • Email: Sending data via corporate email
  • FTP/SFTP: Traditional file transfer

DNS Tunneling Detection

DNS tunneling hides data in DNS queries. Detection indicators:

IndicatorNormalSuspicious
Query length< 50 chars> 100 chars
Subdomain depth2-3 levels5+ levels
Query volumeVariesHigh frequency to same domain
TXT record requestsRareFrequent TXT queries
EntropyLow (readable)High (encoded data)

Detecting Large Data Transfers

SPL
index=network sourcetype=firewall
| stats sum(bytes_out) as total_bytes by src_ip, dest_ip
| where total_bytes > 100000000
| eval MB=round(total_bytes/1024/1024,2)
| sort -MB

DNS Analysis Queries

SPL
index=dns 
| eval query_length=len(query)
| eval subdomain_count=mvcount(split(query,"."))
| where query_length > 50 OR subdomain_count > 4
| stats count by query, src_ip
| sort -count

🎯THE CHALLENGE

SITUATION: Your DLP system detected potential data leakage but couldn't identify the method. Network logs show unusual traffic patterns. Analyze the DNS and network logs to find:


1. The internal IP performing DNS tunneling
2. The domain used for the tunnel
3. The approximate data size exfiltrated (in MB)

FLAG FORMAT
FLAG{IP_DOMAIN_SIZE}
📥 Download Challenge Data
💡 HINT

Look for unusually long DNS queries or high volume of queries to the same domain. Calculate the data based on query count × average encoded bytes per query.

🔓SOLUTION

Identify Unusually Long DNS Queries

SPL
index=dns sourcetype=dns_logs
| eval query_len=len(query)
| where query_len > 60
| stats count, avg(query_len) as avg_len by src_ip
| sort -count

IP 10.10.5.23 has 4,782 queries with avg length 127 chars!

Find the Tunnel Domain

SPL
index=dns sourcetype=dns_logs src_ip="10.10.5.23"
| rex field=query "\.(?[^.]+\.[^.]+)$"
| stats count by base_domain
| sort -count

Tunnel domain: data-sync.evil.com (4,782 queries)

Analyze Query Patterns

SPL
index=dns sourcetype=dns_logs src_ip="10.10.5.23" query="*data-sync.evil.com"
| eval encoded_data=replace(query,"\.data-sync\.evil\.com$","")
| eval data_bytes=len(encoded_data)*0.75
| stats sum(data_bytes) as total_bytes, count
| eval MB=round(total_bytes/1024/1024,0)

Total data: ~15 MB exfiltrated via DNS!

Timeline the Exfiltration

SPL
index=dns sourcetype=dns_logs src_ip="10.10.5.23" query="*data-sync.evil.com"
| timechart span=5m count
| where count > 50
