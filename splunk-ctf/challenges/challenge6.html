👤 Lateral Movement

HARD 400 POINTS ~60 MIN T1021

Track an attacker moving through the network using RDP, PsExec, and WMI.

📚CONCEPTS TO LEARN

What is Lateral Movement?

Lateral movement is when attackers move from one compromised system to another within a network. They do this to:

  • Find valuable targets (domain controllers, file servers)
  • Escalate privileges
  • Maintain persistence
  • Access sensitive data

Common Lateral Movement Techniques

TechniqueEvent IDsDescription
RDP (T1021.001)4624 (Type 10)Remote Desktop connections
SMB/Windows Admin Shares (T1021.002)5140, 5145Accessing \\host\C$ or \\host\ADMIN$
PsExec7045, Sysmon 1Service installation, PSEXESVC
WMI (T1047)Sysmon 1WmiPrvSE.exe spawning processes
WinRM/PS Remoting4624 (Type 3), 91, 168Remote PowerShell sessions

Key Windows Event IDs

  • 4624: Successful logon - check Logon Type field
  • 4648: Explicit credentials used (RunAs)
  • 5140: Network share accessed
  • 7045: New service installed
  • 4688: Process creation (needs audit policy)
Logon Types
Type 2:  Interactive (local console)
Type 3:  Network (SMB, remote access)
Type 7:  Unlock
Type 10: RemoteInteractive (RDP)
Type 11: CachedInteractive

Building a Movement Timeline

SPL
index=windows (EventCode=4624 OR EventCode=4648)
| eval movement_type=case(
    LogonType=10, "RDP",
    LogonType=3, "Network",
    EventCode=4648, "Explicit Creds"
)
| stats earliest(_time) as first_seen by src_ip, dest_host, user, movement_type
| sort first_seen

🎯THE CHALLENGE

SITUATION: An attacker compromised a workstation and is moving through your network. Your task is to map their path by analyzing Windows Security and Sysmon logs. Find:


1. The initial compromised host
2. The number of unique hosts the attacker accessed
3. The final target (domain controller name)

FLAG FORMAT
FLAG{INITIAL_HOST:COUNT:DC_NAME}
📥 Download Challenge Data
💡 HINT

Start by finding the earliest logon with a suspicious source. Then trace that user's activity across hosts. Use the transaction command to group related events.

🔓SOLUTION

Find All Network Logons

SPL
index=windows EventCode=4624 (LogonType=3 OR LogonType=10)
| stats count by src_ip, dest_host, user, LogonType
| sort -count

Unusual: User "admin_backup" logging in from multiple workstations!

Trace the Attack Path

SPL
index=windows EventCode=4624 user="admin_backup"
| table _time, src_ip, dest_host, LogonType
| sort _time

Timeline shows: WKSTN-PC12 → WKSTN-PC45 → SRV-FILE01 → SRV-APP02 → DC01

Count Unique Hosts

SPL
index=windows EventCode=4624 user="admin_backup"
| stats dc(dest_host) as unique_hosts, values(dest_host) as hosts

5 unique hosts accessed

Identify Initial Compromise

SPL
index=windows EventCode=4624 user="admin_backup"
| stats earliest(_time) as first_access by src_ip
| sort first_access
| head 1

Initial source was WKSTN-PC12 (first lateral movement originated here)

Visualize the Attack Path

SPL
index=windows EventCode=4624 user="admin_backup"
| transaction user maxspan=4h
| table _time, src_ip, dest_host
| sort _time

FLAG{WKSTN-PC12:5:DC01}
