⏰ Persistence Hunter

HARD 500 POINTS T1547

Find registry-based persistence and scheduled tasks planted by attackers.

📚CONCEPTS TO LEARN

Sysmon Events for Persistence

  • Event ID 12: Registry object added/deleted
  • Event ID 13: Registry value set
  • Event ID 1: Process creation (schtasks, reg.exe)

🎯THE CHALLENGE

SITUATION: After remediating an incident, find all persistence mechanisms. Identify:

1. The malicious scheduled task name
2. The registry Run key value name
3. The malicious executable path

FLAG FORMAT
FLAG{TASKNAME_REGVALUE_EXEPATH}

🔓SOLUTION

Find Registry Persistence

SPL
index=sysmon EventCode=13 TargetObject="*CurrentVersion\\Run*"
| table _time, host, TargetObject, Details

Find Scheduled Tasks

SPL
index=windows EventCode=4698
| table _time, host, TaskName, SubjectUserName
